# Landing Page Replit

Projeto dedicado ao desenvolvimento de uma landing page sobre a plataforma **Replit**, integrando apresentação institucional, diferenciais técnicos e experiência do usuário.

## Estrutura do Projeto

```text
Replit/
├── src/                # Código-fonte principal da página (index.html)
├── assets/             # Folhas de estilo, scripts e mídias
│   ├── css/            # Estilos (style.css, design tokens)
│   ├── js/             # Comportamentos interativos (main.js)
│   ├── img/            # Imagens e capturas de tela
│   └── icons/          # Ícones vetoriais SVG
├── docs/               # Governança e documentação técnica
│   ├── brief.md        # Briefing de conteúdo do projeto
│   ├── plan.md         # Roteiro de implementação
│   ├── log.md          # Diário de bordo e Handoff Rápido
│   └── adr/            # Decisões arquiteturais registradas
├── _backup/            # Backups locais (ignorado no Git)
└── AGENTS.md           # Diretrizes do workspace para agentes IA
```

## Execução Local
Acesse a pasta `src/` e abra o arquivo `index.html` em qualquer navegador web moderno.
