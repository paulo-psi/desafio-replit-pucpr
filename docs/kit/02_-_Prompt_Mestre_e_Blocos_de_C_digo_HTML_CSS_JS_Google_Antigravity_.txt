2. Prompt Mestre Atualizado para Colar no Google Antigravity
# MISSÃO: CRIAR O PORTAL INTERATIVO DE BOAS-VINDAS — HACKATHON REPLIT


Atue como Product Designer Sênior, Especialista em UX Educacional e Engenheiro Front-End. Construa uma aplicação web completa, responsiva e em arquivo único (`index.html` com CSS e JS embutidos, zero dependências externas que possam quebrar offline) intitulada **"Do Zero ao Software: Guia Oficial do Hackathon Replit"**.


## CONTEXTO E PÚBLICO-ALVO
- **Tema do Hackathon:** "Chegue com uma ideia e saia com um software".
- **Público:** Leigos totais (sem experiência prévia em programação ou ferramentas de desenvolvimento).
- **Tom de Voz:** Cordial, direto, encorajador, lúdico e 100% em português do Brasil (pt-BR), traduzindo termos técnicos para metáforas do dia a dia.
- **Orçamento:** Cada participante receberá **US$ 20 em créditos** no Replit. O guia deve ensinar de forma visual e prática como fazer esse saldo durar até o Pitch final.


## COMPONENTES OBRIGATÓRIOS DA INTERFACE
1. **HUD Superior Fixo (Gamificação):** Exibe a patente atual do participante (5 níveis, de "Sonhador com uma Ideia" até "Fundador com Software no Ar"), barra de progresso percentual salva em `localStorage` e botão discreto para resetar progresso.
2. **Hero Section Acolhedora:** Título de boas-vindas, explicação da regra de ouro ("Você é o Diretor do Produto; o Replit Agent é o seu Engenheiro"), botão de acesso direto ao Replit (`https://replit.com`) e os 2 vídeos de aquecimento de menos de 1 minuto.
3. **Mapa Visual da Tela do Replit (Simulador Annotated):** Representação visual em CSS Grid da interface do Replit (Coluna 1: Chat com o Agent e botão Plan; Coluna 2: Tela do App ao vivo; Barra Superior: botão Publish e aba Secrets).
4. **Plano de Guerra dos US$ 20 (3 Fases):** Cards explicando como dividir o saldo (Fase 1: Plan Mode ~US$ 1; Fase 2: Construção do MVP ~US$ 12; Fase 3: Ajustes no modo Lite ~US$ 7) + alerta sobre escolher **Autoscale** (e nunca Reserved VM) na publicação.
5. **Montador Interativo de Prompt + 3 Modelos Prontos + Duelo de Prompts:** Um mini-formulário de 3 campos (Nome da Ideia, Público-Alvo, Ação Principal) que gera o prompt profissional em tempo real, acompanhado de abas com exemplos prontos, comparador Errado vs. Certo e botão de copiar resiliente (`copiarSeguro`).
6. **Central Anti-Pânico (Protocolo de Emergência):** Card interativo ensinando a **Regra das 2 Tentativas** (se o erro persistir após 2 pedidos, acionar o botão Rollback to here no Checkpoint anterior em vez de gastar créditos insistindo).
7. **Videoteca Auditada com Filtros + Biblioteca de Apoio:** Galeria filtrável por duração com os links auditados do YouTube e seção separada para a Documentação Oficial em PT-BR, Artigo Alura e Apostila PDF.
8. **Checklist Final Pré-Pitch:** 5 a 6 passos verificáveis com feedback visual ao concluir 100%.


## INSTRUÇÕES DE EXECUÇÃO NO ANTIGRAVITY
1. Gere primeiro o plano de implementação estruturado.
2. Escreva o código completo e limpo em `index.html` integrando fielmente os blocos estruturais e links auditados fornecidos abaixo.
3. Inicie o navegador integrado do Antigravity para validar visualmente o layout em desktop e mobile, testar o gerador de prompt em tempo real, o botão de cópia, os filtros de vídeo e a persistência do checklist, entregando um Walkthrough resumido ao final.

function fallbackCopiar(texto, callback) {
const area = document.createElement('textarea');
area.value = texto;
area.style.position = 'fixed';
area.style.opacity = '0';
document.body.appendChild(area);
area.focus();
area.select();
try { document.execCommand('copy'); callback(); } catch (e) { alert('Selecione o texto e pressione Ctrl+C'); }
document.body.removeChild(area);
}
